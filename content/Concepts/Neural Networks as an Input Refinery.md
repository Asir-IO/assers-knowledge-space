## Mental Model
A NN can be thought of as an object that, given a set of <mark style="background: #ADCCFFA6;">input</mark> features, sequentially transforms them into more discriminative/high-level features, until finally transforming the *most* <mark style="background: #FF5582A6;">discriminative</mark> features into the <mark style="background: #D2B3FFA6;">output</mark> features.
