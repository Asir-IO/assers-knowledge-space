# Course Project
I built a tool that uses a CNN, RNN (and its siblings), or transformer model to classify an image of a traffic sign into one of the 43 classes in the [GTSRB](https://www.kaggle.com/datasets/meowmeowmeowmeowmeow/gtsrb-german-traffic-sign) dataset.   

The interesting part about this project is that it helped me develop a "model-building" workflow that I think will help me have a smoother experience working on Computer Vision projects in the future.
- psst... *it involves colab and hugging face.*

Also, I came across a tool, [hackMD](https://hackmd.io/IyvwFsrxQoCotaf8j7egJw), that helped me create and easily share the project report.
- I'll def. be using it in the future whenever I need to create a report.
